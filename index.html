// expert dfir — thinking like an analyst

منهجية التحقيق — تفكير محلل DFIR Investigation Mindset — Thinking Like a Professional DFIR Analyst

ليس فقط ماذا تفحص؟ بل لماذا تجمعه؟ متى؟ كيف تحكم بثقة؟ وكيف توسع التحقيق؟ Not just what to check — but why to collect it, when to collect it, how to judge with confidence, and how to expand the investigation.

💻 Live Response مقابل Dead Box Forensics Live Response vs Dead Box Forensics

Live Response يتم أثناء تشغيل الجهاز، يركز على الأدلة المتطايرة. Dead Box Forensics يتم على جهاز مطفأ أو صورة قرص، يركز على آثار القرص. Live Response is performed while the system is running, focusing on volatile evidence. Dead Box Forensics is performed on a powered-off system or forensic image, focusing on disk artifacts.

لا تحكم من اسم الأثر فقط — صنّفه بناءً على السياق والسلوكDon't judge an artifact by its name alone — classify by context, path, signer, and behavior
💡 مثال:Example: powershell.exe طبيعي إذا شغّل من System32 لأغراض إدارية، لكنه مشبوه إذا تم تشغيله من winword.exe مع أمر مشفّر. powershell.exe is normal when launched from System32 for administration — but suspicious when launched by winword.exe with an encoded command.
🧬
أهمية العملية الأم (Parent Process)Parent Process Matters
العملية الأم غالبًا تشرح القصة أفضل من اسم العمليةThe parent process often explains the story better than the process name itself

اسأل دائمًا: ما الذي شغّل العملية المشبوهة؟ هل Office شغّل PowerShell؟ هل المتصفح شغّل ملف تنفيذي؟ Always ask: what launched the suspicious process? Did Office spawn PowerShell? Did a browser launch an executable?

أمثلة مشبوهةSuspicious Examples

services.exe→cmd.exe→powershell.exe

استخدم السياق قبل الحكمUse Context Before Judgement
مؤشر واحد نادرًا ما يكفي لإعلان حادثةA single IOC is rarely enough to declare an incident

اجمع بين عدة إشارات: سلوك العملية، العملية الأم، نشاط المستخدم، مسار الملف، التوقيع، الوجهة الشبكية، والتوقيت. Combine multiple signals: process behavior, parent process, user activity, file path, signer, network destination, and timing.

🟢 ثقة عاليةHigh Confidence
🟡 ثقة متوسطةMedium Confidence
🔴 ثقة منخفضةLow Confidence
💡 مثال:Example: IP مشبوه وحده = ثقة منخفضة. نفس IP + تشغيل PowerShell + ملف جديد + Persistence = ثقة عالية. Suspicious IP alone = low confidence. Same IP + PowerShell execution + dropped file + persistence creation = high confidence.
